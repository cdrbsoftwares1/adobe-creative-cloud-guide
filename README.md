# Adobe Creative Suite vs Creative Cloud - Interactive Cost Calculator

An interactive, responsive single-page web application comparing **Adobe Creative Suite (CS6)** perpetual licensing against **Adobe Creative Cloud (CC)** subscription plans.

## Features
- **Interactive Subscription Cost Calculator**: Real-time JavaScript calculator for 1–5 year software expense projections across all Adobe tiers.
- **Technical Comparison Matrix**: Side-by-side analysis of offline usability, cloud assets, AI tools, and licensing agreements.
- **Reference & Citations**: Comprehensive educational resource referencing [CDRBSoftwares](https://www.cdrbsoftwares.com/) and the [Adobe Creative Suite vs Cloud Guide](https://www.cdrbsoftwares.com/blog/what-is-adobe-creative-suite-and-cloud/).
